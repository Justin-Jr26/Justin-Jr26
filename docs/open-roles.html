POSITION 01 / LLM FOUNDATION TRAINING

LLM-预训练算法工程师

TransformerMoEScaling LawsDistributed Training

01 / 岗位职责 · RESPONSIBILITIES

  1. 模型结构设计与优化：深入研究并优化大语言模型基础架构（如 Transformer 及其变体、MoE 等），探索高效 Attention 机制、位置编码及新型网络结构，突破长上下文（Long-context）和推理效率瓶颈。
  2. 预训练策略与 Scaling 研究：负责超大规模参数模型预训练，研究 Scaling Laws，指导算力与数据规模的最优分配；探索训练策略（如 Curriculum Learning、优化器改进、学习率调度等），持续提升模型基础能力。
  3. 预训练数据策略：分析海量多模态、多语言预训练数据分布，设计数据混合（Data Mix）与采样算法；研究数据质量与模型能力的关联，针对性提升逻辑推理、代码编写、数学计算等核心表现。
  4. 分布式训练与稳定性保障：基于千卡、万卡级算力集群，与系统工程团队联合优化 DeepSpeed、Megatron-LM 等分布式训练框架，定位和解决 Loss Spike、梯度不稳定或不收敛等问题，保障大规模训练效率与稳定性。

02 / 岗位要求 · QUALIFICATIONS

  1. 学历专业：计算机、人工智能、数据科学、数学等相关专业硕士及以上学历。
  2. 编程功底：扎实的算法与数据结构能力，精通 Python，熟练掌握 C++，具备出色的工程实现能力。
  3. AI 与框架底座：深入理解 NLP/LLM 基础理论，熟练使用 PyTorch，对大模型核心算子有深入了解。
  4. 分布式计算：熟悉至少一种主流大规模分布式训练框架（如 Megatron-LM、DeepSpeed、Colossal-AI），理解数据并行、张量并行、流水线并行及 ZeRO 等内存优化技术。
  5. 问题解决：较强的 Debug 和问题诊断能力，能够定位并解决模型训练中的算法缺陷与系统瓶颈。
POSITION 02 / MULTIMODAL UNDERSTANDING

多模理解-视觉语言大模型研究员

ViT PretrainVLM PretrainVLM Post TrainUnified Gen/Understanding

01 / 岗位职责 · RESPONSIBILITIES

参与视觉语言大模型研发，负责以下至少一个或多个方向：

  1. ViT Pretrain：提升模型感知能力，包括 Vision Encoder Pretrain 算法架构及多种感知能力数据构建。
  2. VLM Pretrain：提升 VLM 预训练通用能力，探索不同训练阶段的设计、通用数据的组织形式。
  3. VLM Post Train：提升 VLM 通用能力，包括合成数据、RL 等方法。
  4. 生成理解统一：探索生成与理解统一架构，同时提升理解能力和生成能力。

02 / 任职资格 · QUALIFICATIONS

  1. 本科及以上学历，计算机等相关专业优先。
  2. 熟练阅读、编写代码，熟练使用 Agentic AI 能力；在 Python、PyTorch 技术栈有深入实践。
  3. 在视觉领域有深入实践和理解，具备一定深度的专业认知与见解。
  4. 具备良好的科学研发习惯、问题定义能力和对细节的敏锐度。
POSITION 03 / GENERATIVE VIDEO FOUNDATION

视频生成基座模型算法专家

Video GenerationDiffusionTransformerAlignment

01 / 职位描述 · RESPONSIBILITIES

  1. 负责大规模视频生成基座模型的全流程研发，覆盖架构设计、预训练、SFT、对齐优化全链路，从零打造具备行业竞争力的视频生成模型。
  2. 追踪全球前沿技术进展，重点攻坚 Diffusion 与 Transformer 路线在视频生成领域的最新突破，开展原创性技术研究与方案预研，持续保持技术领先性。
  3. 与数据工程、Infra 团队深度协同，定义模型迭代的数据需求、训练策略与算力优化方案，推动模型规模化稳定训练与效果持续迭代。

02 / 职位要求 · QUALIFICATIONS

  1. 硕士及以上学历，计算机、人工智能等相关专业；具备深厚的机器学习和深度学习理论功底，对扩散模型或自回归模型有第一性原理级的深度理解。
  2. 有从零参与或主导大规模生成式模型（图像 / 视频）全链路训练的实战经验，熟练掌握 SFT、RLHF 等对齐技术，具备完整的模型调优与问题排查能力。
  3. 极强的论文复现与工程落地能力，理解技术商业价值，能够以技术支持公司长期战略与市场竞争力建设。
  4. 发表 CVPR、ECCV、ICCV、NeurIPS、ICLR、SIGGRAPH、SIGGRAPH Asia 等顶会论文者优先。
